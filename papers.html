Query the Vector Database Directly

Search today's arXiv releases or filter by conference (venue=arxiv-today|neurips|iclr|icml|acl-emnlp|systems-conf): 

curl -s "https://api.spaceresearch.ai/v1/papers/search?q=FP4+attention+kernel&venue=arxiv-today&mode=hybrid&k=5" | jq '.results[] | {published_date, title, vector_score, arxiv_id}'

Search NeurIPS / ICLR / ICML mechanistic interpretability papers: 

curl -s "https://api.spaceresearch.ai/v1/papers/search?q=sparse+autoencoder+circuits&venue=neurips&k=5" | jq '.results[] | {venue, title, vector_score}'

Direct Python query against the persistent SQLite + sqlite-vec database: 

from network.papers_db import PapersVectorDB

db = PapersVectorDB("artifacts/papers_vectordb.sqlite")
res = db.search("Blackwell FP4 Triton attention kernel", venue="arxiv-today", k=8)
for p in res["results"]:
    print(f"[{p['vector_score']:.3f}] {p['published_date']} · {p['title']}")
